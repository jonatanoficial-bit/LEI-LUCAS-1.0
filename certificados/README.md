# Portal de Registros — Instituto Musical Vale

Página pública do portal: \`/certificados/\`

## Como atualizar alunos
1. Abra \`certificados/admin.html\` no site.
2. Preencha o formulário.
3. Clique em **Baixar data.json atualizado**.
4. No GitHub, substitua o arquivo \`certificados/data.json\` pelo novo arquivo.
5. O GitHub Pages atualizará automaticamente.

## Estrutura
- \`index.html\`: portal público.
- \`styles.css\`: identidade visual.
- \`app.js\`: busca, filtros, cartões e detalhes.
- \`data.json\`: cursos e alunos.
- \`admin.html\`: gerador local de novos registros.
- \`logo.webp\`: logo oficial otimizado para web.

## Privacidade
O portal não deve armazenar RG, CPF, endereço, dados de saúde ou outros dados sensíveis.
Como os nomes ficam públicos no GitHub Pages, mantenha base legal e/ou autorização institucional adequada para essa publicação.
